Konfiguration

Rechner

Pro Rechner wird der Port-Bereich abgesucht. Welche Engine läuft (Maya, Basalt, Strata …), erkennt das Dashboard selbst über /v1/status → service. Zieht ein Modell auf einen anderen Rechner um, erscheint es automatisch dort. Es werden nur private LAN- oder Tailscale-Adressen abgefragt.

Engines (Darstellung)

Zuordnung über den service-Namen, den der Server meldet. Unbekannte Engines erscheinen trotzdem, nur grau und mit dem Namen aus service. Der UI-Pfad wird an http://host:port angehängt und ergibt den Link „Monitor ↗“.

API-Keys

Bei jedem gefundenen Server werden die Keys der Reihe nach ausprobiert, der erste passende wird genommen. Gespeicherte Keys sind maskiert und bleiben erhalten, solange du sie nicht ersetzt. Key-Dateien sind JSON-Dateien mit einem Feld api_key, etwa die Run-Config von Maya. Sie werden bei jeder Suche neu gelesen.
